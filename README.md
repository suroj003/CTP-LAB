## About the Repository

This repository contains the programs and practical work completed for the **Computational Tools and Programming Lab (CS22005)**.

The practicals cover Python programming, Object-Oriented Programming, numerical computing, data analysis, visualization, databases, GUI development, web scraping, XML processing, and Git/GitHub version control.
